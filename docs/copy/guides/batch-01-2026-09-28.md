# 3 Admin Jobs to Hand Claude This Week

**Three jobs you can hand to Claude today: messy meeting notes, a question about a long document, and a rough email. Here's the prompt for each, and the one check that keeps you safe.**

Beginner · 10 minutes · Free Claude account · By Fatiha Chikh

**What you leave with:** 3 prompts you can reuse every week, a worked example for each, and a 30-second check before you use the answer.

### 01 · How to use this guide
Pick the job that annoys you most this week. Try it with the example first, so you can see what a good answer looks like. Then swap in your own material. Leave out anything confidential (see *What can I safely paste in?*).

### 02 · Job 1: Messy notes into clear actions
**The job:** you have notes from a meeting and nobody knows who's doing what.
**Why Claude:** it's good at keeping the nuance. When something was *suggested*, it tends to keep it as a suggestion rather than turning it into a decision.
**Try it with this example:**
> The team agreed to run a pilot. The programme lead will draft the invitation by 8 October. Operations will check room availability, but no deadline was set. Budget approval is pending. A launch on 22 October was suggested, not confirmed.

**What a good answer looks like:**
> **Decision:** run a pilot.
> **Actions:** programme lead drafts the invitation by 8 October · operations checks the room (deadline not agreed).
> **Still open:** budget approval · the launch date.

**Why Claude:** it reads long documents well and can quote the exact line it used, so you can check it.

**The job:** you know what you want to say but not how to say it.

# Stop ChatGPT Writing You an Essay

**"Make it shorter" doesn't work because ChatGPT doesn't know what *short* means for you. Tell it the parts you need and a word limit, then check it didn't cut the truth.**

Beginner · 5 minutes · Any ChatGPT account · By Fatiha Chikh

**What you leave with:** a short-answer prompt you can reuse, plus a 4-point check.

### 01 · How to use this guide
Read the example, try the prompt as it is, then swap in facts from your own work.

### 02 · Say what "short" means
Instead of: *"Make this shorter."*
Try: *"Write a meeting update in 3 bullets, under 60 words."*
Name the parts (for example Status, Waiting on, Next action) and the limit. That's usually all it takes.

### 03 · Short is only useful if it's still true
**Your facts:** the onboarding checklist draft is ready. Team leads haven't reviewed it. No publication date has been agreed.
**Too confident:** "The checklist is ready to publish soon." *(It added an approval and a timeline you don't have.)*
**Short and accurate:** "The draft is ready. Team lead review and a publication date are still open."

▒ locked ▒ *The full prompt*

### 04 · The honest part
When AI shortens, it tends to round things up: "under review" becomes "approved". The shorter the answer, the more carefully you check each word.

### Sign-up block
**The rest is yours.** The full short-answer prompt and the 4-point check. Free · no card.
**Button:** Show me the prompt

### After sign-up
**The short-answer prompt**
```
Write a short update using only these facts:
[paste your facts]

Give me exactly 3 bullets headed Status, Waiting on and Next action. Keep it to 60 words or fewer. No introduction or closing offer. Don't say anything is approved or decided unless my facts say so. If the next action isn't clear, say what still needs to be agreed.
```

**The 4-point check**
1. Can you find all 3 parts?
2. Is it 60 words or fewer?
3. Does every statement match your facts?
4. Did you delete any intro, repetition or invented detail?

**A new chat starts from zero. If you keep repeating the same brief, put it in a ChatGPT Project once, and every chat inside that Project can use it.**

Beginner · 15 minutes · ChatGPT account with Projects [VERIFY which plans] · By Fatiha Chikh

**What you leave with:** a working Project, the brief to paste into it, and a 2-chat test that proves it remembers.

### 01 · How to use this guide
Use the example event first, so you can see whether the second chat keeps the brief without being reminded. Then build a Project for your real work.

### 02 · One question, or ongoing work?
- **One question:** a normal chat is fine.
- **Several chats on the same work** (a client, an event, a project): use a Project. It keeps related chats, files and instructions together.

### 03 · The example: an event brief that stays the same

### 04 · The honest part
A Project keeps instructions, but it doesn't guarantee every answer follows them. That's why the guide ends with a test: if the second chat misses a fact, check that both chats are inside the same Project and that the instructions were saved.

# The 3-Question Check Before You Paste Anything Into AI

**Some things should never go in, some need permission first, and some are fine. Run the 3-question paste test before you share anything.**

Beginner · 5 minutes · Any AI tool · By Fatiha Chikh

**What you leave with:** the paste test, a keep-out / ask-first / fine list, and a prompt that checks a task without you sharing the real data.

### 01 · How to use this guide
Read the 3 questions, sort what you were about to paste, then use the test prompt with categories only, never the real information.

### 02 · The paste test
1. **Do I need it?** Could the task work without the real details?
2. **Am I allowed?** Do I have permission to share this?
3. **Is this the right tool?** Is this account approved for work?

If any answer is "no" or "not sure", replace the real details with an invented example.

### 03 · Keep out · Ask first · Fine
- **Keep out:** passwords, bank details, health information, anything under a confidentiality agreement.
- **Ask first:** customer emails, colleagues' names, internal documents, contracts.
- **Usually fine:** public website text, your own rough notes without names, invented examples.

Turning off "training" in a tool's settings gives you more control, but it doesn't give you permission to share confidential work. Permission comes from your company, not from a setting.

# Read This Before You Connect AI to Your Email

**Only give AI the access the job needs. Often one uploaded file is enough, and you don't need to connect anything.**

Beginner · 10 minutes · ChatGPT, Claude, Gemini or Copilot · By Fatiha Chikh

**What you leave with:** a simple way to choose the smallest access, a prompt that explains any permission screen in plain words, and where to switch access off.

### 01 · How to use this guide
Decide what the job needs, check the permission screen before you approve, and know where to disconnect.

### 02 · Choose the smallest access
1. **Upload one file:** best for one document and one task. No connection needed.
2. **Connect one service** (for example Gmail or Drive): when the AI needs to search across many items.
3. **Allow actions** (send, edit, delete): only when you really need it, and never as your first step.

### 03 · Read the permission screen before you click
Look for these words: *read, create, edit, delete, send, share*. Each one is a different level of access.
In ChatGPT, for example, "Allow read actions" means it can read from the connected app without asking each time, but it still asks before making changes. [VERIFY]

### 04 · Where to switch it off
ChatGPT: **Settings → Apps** (or Plugins, if shown), then choose the account to disconnect. [VERIFY] The paths for Claude, Gemini and Copilot are in the full guide. [VERIFY]
Turning a connector off for one chat may leave the account connected. Check the account connection too.

### 05 · The honest part
Always check the AI's explanation against the real permission screen. The screen decides what the tool can do, not the AI's summary of it.
