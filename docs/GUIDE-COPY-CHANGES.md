# AI Automation Queen: editorial changes to the 35 approved guides

**Scope:** all 35 approved Next.js guide routes, reviewed using each guide’s full source object and its custom interactive renderer. These are targeted copy improvements, not a wholesale reset. Source examples, useful interactive lessons, prompts, safeguards and links stay in place unless the exact entry below says otherwise.

**Writing method:** make the task, first action, small example, verifiable result and stopping condition more useful. This adapts the *teaching structure* observed on Saadia Karam’s public guides, not her prose, tone or examples. Newly added reader-facing copy contains no em dashes. The guide collection is credited to AI Automation Queen; the professional Shift & Lead homepage and About page retain Fatiha’s name.

**How it reaches readers:** each guide has a specific open lesson before the existing optional-marketing Lumail email pass, followed by its original interactive teaching with selective edits. No marketing list signup occurs merely because a reader requests the guide email.
