# Tenant Template

Copy this folder to `tenants/<client-slug>/` to onboard a new client. Then fill
the brain files using their profiling pass (positioning, audience, voice,
pillars), wire their connections in `tenant.json`, and fill `lead-magnets.csv`.

See `../README.md` for the onboarding checklist.

## Files to fill in

- `tenant.json` — connections + schedule (use env-var names for keys, never paste)
- `positioning/SKILL.md` — the identity layer (copy from root, replace contents)
- `inventory.md` — channels, offers, tools (copy from root)
- `content-vault.md` — start with the header, add ENTRY 001+ as they're built
- `research-notes.md` — empty, ready for signal-harvester
- `lead-magnets.csv` — comment-keyword CTAs + resource URLs

## Files inherited from root (no copy needed)

- The skills (`skills/`)
- The dashboard code (`dashboard/`)
- The inspiration library (`inspiration-library/`)
- Build-log + roadmap discipline (`ROADMAP.md`)
- Security policy (`security.md`)
