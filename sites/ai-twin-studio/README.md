# Shift & Lead AI Twin Studio

The source for the Shift & Lead AI Twin Studio website. It presents the AI twin offer through the current Shift & Lead visual identity and entrepreneur-focused positioning.

## Run locally

```bash
npm ci
npm run dev
```

## Validate

```bash
npm run build
```

## Key files

- `app/page.tsx` - page content and structure
- `app/globals.css` - responsive visual system
- `app/layout.tsx` - metadata, fonts, and social sharing
- `public/` - Shift & Lead brand assets and social card
