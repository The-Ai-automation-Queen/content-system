## Source decision

The legacy page provides the useful starting idea: a prompt is a clear brief, not a clever command. The workbook sources add the mechanics that improve a real result: a clear goal, relevant context, approved source material, a good example, useful limits, an exact output format, questions when information is missing, several distinct options when direction is unclear and a review loop.

The rewrite does not reproduce the source prompts, creator voice, slogans, bylines, tool promotion, productivity claims or product-specific instructions. Advanced prompt patterns remain source material for the later Better prompts and answers hub. This Beginner guide teaches 1 durable method.

## Shift & Lead transformation

The new guide packs the complete prompt brief into 4 steps: job and situation, source and example, rules and limits, then output and review. Its practical section shows how Shift & Lead uses the brief for a guide follow-up, then gives the reader the reusable template. The template includes source boundaries, forbidden actions and a human review step, so it remains useful outside the article.
