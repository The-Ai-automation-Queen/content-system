Before you ask
Questions people actually have.
I'm not technical. Can I still do this?

Yes. You need to understand the work you want done, not learn to code. I explain the tools in plain language and start with the work itself.

Do I need an AI agent?

Not necessarily. Some work needs a good prompt. Some needs an automation between tools. An agent makes sense when AI needs to complete several steps and return a finished result.

What is the difference between the guides and the workbooks?

The guides help you use AI in your work and business. The workbooks help you find the patterns in your own experience and decide what to do with them.

What if the free guides are not enough?

If you want to build something specific, see Build with me. If you want to help a team use AI in real work, explore the workshops.
