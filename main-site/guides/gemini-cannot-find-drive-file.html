Why can’t Gemini see the file in your Drive?

Test one made-up document. Find out if the problem is your account, the connection, the search or the file.

IN THIS GUIDE01 · Make a test document02 · Find the blocker03 · What to try next

You will know which check failed and have a safe test request to try again.

Set up a safe test

Make one document Gemini should find

Open Google Docs with the same account you use for Gemini. Create a document called Autumn launch brief demo and paste in this invented text.

Open Google Docs ↗
Complete demo document text
Autumn launch brief demo
Decision: use the blue cover.
Owner: Sam.
Review date: 18 October.
Find the blocker

Check these 5 things in order

Start with the account and connection. Then ask for the demo document and check the answer against the file.

Open Gemini and confirm you are signed in with the same Google account that owns or can open the demo file.

Open Gemini ↗

Type @ in a new Gemini chat and select Google Drive if it appears.

  • Missing from @? In Gemini, open Settings → Connected Apps and check Keep Activity.
  • Will not connect? In Gmail, check Smart features in other Google products.
  • Work or school account? Ask your administrator if connected apps are enabled.

Ask for the file by its exact, unique title and request the source.

Once you select @Google Drive, send this request. The demo text belongs in the document; only this request goes into Gemini.

Continue this guide

Get the Gemini test request

Copy the exact request for the demo document and keep a link to this guide.

Save the link we email you to return later. Privacy notice.
Complete Gemini request
Find the Google Drive file titled “Autumn launch brief demo”. Tell me the decision, owner and review date. Show the source.

Open the source Gemini lists and check that it is the demo file.

If Gemini gives no source, open the document yourself. Do not rely on an answer you cannot compare with the file.

If Gemini finds the demo Doc but not your original file, check the original's type. Google Workspace connection can read documents, spreadsheets, presentations and PDFs, but not Drive pictures or videos.

What did the test show? If Gemini cannot find the demo Doc, revisit the account, connection and request checks. If it finds the Doc, compare its decision, owner and review date with the source before trying your original file.
