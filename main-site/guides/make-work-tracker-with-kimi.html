How to Make a Client Tracker in Excel With AI

AI builds the spreadsheet. You test it with real mistakes. One file for every client, project and next step.

Start the guide ↓
Fatiha Chikh | The AI Automation Queen Free guide
Shift & Lead

One tracker for every client project

Client work often sits in your inbox, your notes and your head. Then things get missed: a follow-up, an invoice you never sent. In this guide, AI asks how you work and builds the Excel file. Then you try to break it before you use it with real clients.

What you end up with

  • A column plan: the 8 columns you need and what each status means
  • Your client project tracker (.xlsx file) with dropdowns (lists to pick from), date checks, red overdue rows and a summary tab
  • The tracker tested with real mistakes: wrong dates, blank owners, made-up statuses
  • A fixed version that catches those mistakes
  • A 10-minute weekly check that keeps it up to date

You need ChatGPT, Claude or Kimi. Any AI that can make an .xlsx file for you to download will work. Excel, Google Sheets or Numbers can open the file. You can copy and paste every prompt below. Replace the parts in [square brackets].

01

Plan the columns Before AI builds anything.

With the wrong columns, people stop using a tracker within a week. Start from these 8. Change them to fit how you work.

ColumnWhat goes in itExample
ClientThe client's name[client]
ProjectWhat you are doing for themWebsite copy, 5 pages
Next actionThe next thing to do, starting with a doing wordSend first draft
OwnerWho does the next actionYou, or your VA
Due dateWhen the next action is due, as a real date17/10/2026
StatusWhere the project is, picked from a listIn progress
Invoice sentYes or No, picked from a listNo
NotesAnything else, one lineWaiting on logo files

Status rules

A status only helps if everyone means the same thing by it. Pick 4 or 5. Write down what each one means.

StatusIt means
Not startedAgreed with the client, no work done yet
In progressYou or your team are working on it now
Waiting on clientYou need something from the client before you can go on
DoneDelivered and accepted. Only the invoice is left.
On holdPaused by you or the client, with a note saying why

Use one row per project, not per task. A client with two projects gets two rows.

02

Let AI interview you How you actually work.

First, let the AI ask how you work. Then the tracker fits your business, not any business.

  1. Open ChatGPT ↗, Claude ↗ or Kimi ↗. Start a new chat.
  2. Paste the prompt below, with your columns and statuses from step 01.
  3. Answer each question. Copy the final column list into your notes.
I want an Excel tracker for my client projects. I'm [what you do, for example: a freelance copywriter] and I usually have [number] client projects at a time.

My starting columns: [paste your columns from step 01]
My statuses and what they mean: [paste your status rules]

Before you build anything, ask me up to 6 questions about how I work, one at a time, and wait for each answer. Ask about: who updates the tracker, when I check it, what "done" means for me, how I know an invoice is due, and what I forget most often.

03

Build the file Dropdowns, dates, a summary.

Now the AI builds the real Excel file. The prompt asks for checks that keep the tracker tidy.

Build my client project tracker as an editable Excel file (.xlsx).

Sheet 1, called "Projects":
- Columns: [paste the final column list]
- Status is a dropdown with only these options: [paste your statuses]
- Invoice sent is a dropdown: Yes, No
- Due date only accepts real dates (DD/MM/YYYY). Anything else shows an error message: "Enter a date like 17/10/2026"
- Owner is highlighted when it's blank
- The whole row turns light red when the due date has passed and Status is not Done
- Freeze the header row, and turn on filters for every column
- The dropdowns and checks must work on at least 200 rows, not only the ones with data

Sheet 2, called "Summary":
- How many projects are in each status
- How many are overdue
- How many are Done with Invoice sent = No
These must update by themselves when Sheet 1 changes.

Add these 3 practice rows: [paste 3 made-up projects, for example: Client A, website copy, send first draft, me, next Tuesday, In progress, No].
Leave any cell I didn't give you blank. Never invent clients, dates or amounts.

Give me the .xlsx file to download, then list every dropdown, check and formula you added.
  1. Download the file. Open it in Excel, Google Sheets or Numbers.
  2. Click a Status cell. You should see a small arrow with your statuses.
  3. Does the AI say it can't make files? Look for a file, code or agent button in the tool and turn it on. Or try one of the other two tools. Still stuck? Ask it for the column list and formulas (the sums the sheet does). Then build the sheet yourself.

Use made-up projects until the tracker passes the break-it test in step 04. Add real client names only after that.

04

Try to break it Before you trust it.

Real people type "tomorrow" in a date cell. They forget the owner. Find out now what your tracker does. Do each test and write down what happens.

TestDo thisIt passes if
Wrong dateType "tomorrow" in a Due date cellIt says no and shows your error message
Impossible dateType 31/02/2026It says no
Blank ownerDelete the Owner in one rowThe cell is highlighted
Done-ish statusType "done-ish" in a Status cellIt says no: only list options allowed
OverdueSet a due date last week, Status In progressThe row turns red
FinishedChange that row's Status to DoneThe red goes away
UnpaidLeave a Done row with Invoice sent = NoThe Summary counts it
New rowAdd a project at the bottomThe lists and checks work there too
SortingSort by Due dateEvery row stays together

Every test that fails goes on your fix list for step 05.

05

Fix what broke Only what broke.

Go back to the same chat. The AI still has the file it built there. Give it your fix list.

I tested the tracker. These tests failed:
[list each failed test, what you did and what happened, for example: I typed "tomorrow" in Due date and it was accepted]

Fix only these problems. Don't change the columns, the dropdown options, the Summary sheet or the practice rows.
Tell me what you changed for each problem, then give me the new .xlsx file.
  1. Download the new file. Run the failed tests again.
  2. Still failing after two tries? Start a new chat. Upload the file and paste the fix prompt again.
  3. When every test passes, delete the practice rows. Add your real client projects.
  4. Save the file where you will find it every week. For example, a Clients folder in OneDrive, Google Drive or Dropbox.
06

Check it weekly 10 minutes, same time.

A tracker only works if it is up to date. Book 10 minutes at the same time each week. For example, Monday at 9:00. Do these 4 things.

  1. Red rows first (3 minutes). For each late project, do the next action or change the date. Or write in Notes why it is late.
  2. Blank owners (1 minute). Every project needs a name in Owner.
  3. Done but no invoice (3 minutes). Open the Summary sheet. Send every invoice it lists. Then change Invoice sent to Yes.
  4. New work (3 minutes). Add a row for each new project from your inbox, calls and messages.

The honest part: the tracker won't update itself. It won't chase a client for you. Do you work with a VA (virtual assistant) or freelancer? Agree who updates it and when. AI built the file. Keeping it true is still your job.
