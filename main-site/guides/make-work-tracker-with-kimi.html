How to Make a Client Tracker in Excel With AI

One Excel file for every client, project and next step.

Start the guide ↓
Fatiha Chikh Free guide
Shift & Lead

Get one file for client work

Client work hides in your inbox, notes and head. This guide has AI build one Excel tracker you test yourself. It takes 30 minutes.

What you end up with

  • One Excel file with a row for each client project
  • A next step, owner and due date for every project
  • Late rows that turn red by themselves
  • A summary count of finished work with no invoice sent

You need ChatGPT ↗, Claude ↗ or Kimi ↗, on a plan that can make files, plus Excel, Google Sheets or Numbers. Copy each prompt as it is and change the [brackets].

01

Plan the columns Before AI builds anything.

Wrong columns get a tracker dropped in a week. Start from these 8 and cross out any you would never fill in.

ColumnExample
Client[client]
ProjectWebsite copy, 5 pages
Next actionSend first draft
OwnerYou, or your VA (virtual assistant)
Due date17/10/2026
StatusNot started, In progress, Waiting on client, Done, On hold
Invoice sentYes or No
NotesWaiting on logo files

Then write 3 made-up projects in a note. One late, one with no owner. You test the file with these first.

02

Let the AI ask first So it fits your work.

A few questions first make the tracker fit how you work.

  1. Open your AI tool and click New chat.
  2. Paste the prompt below with your columns from step 01. Press Enter.
I want an Excel tracker for my client projects. I'm [what you do] and I usually have [number] client projects at a time.

My starting columns: [paste your columns]
My statuses: [paste your statuses]

Before you build anything, ask me up to 6 questions about how I work, one at a time. Ask about who updates it, what "done" means for me, and how I know an invoice is due.

Then give me the final columns and statuses, and anything you would remove.
Don't build the file yet. Use only what I tell you.

Answer each question in a sentence. Stay in this chat for step 03.

03

Build the file Dropdowns, date checks, a summary.

Now the AI makes the real .xlsx file. Dropdowns (small lists you pick from) stop made-up statuses.

Build my client project tracker as an editable Excel file (.xlsx).

Sheet 1, called "Projects":
- Columns: [paste the final columns]
- Status is a dropdown with only: [paste your statuses]
- Invoice sent is a dropdown: Yes, No
- Due date only accepts real dates (DD/MM/YYYY). Anything else shows: "Enter a date like 17/10/2026"
- Owner is highlighted when blank
- The row turns light red when the due date has passed and Status is not Done
- Freeze the header row and turn on filters
- Dropdowns and checks work on at least 200 rows

Sheet 2, called "Summary": how many projects in each status, how many overdue, and how many Done with Invoice sent = No. These update by themselves.

Add these 3 practice rows: [paste your 3 made-up projects].
Leave any cell I didn't give you blank. Never make up clients, dates or amounts.
Give me the .xlsx file, then list every dropdown, check and formula you added.
  1. Click the file in the answer to download it. Open it.
  2. Click a Status cell. You should see your list.
  3. Check the late practice row is light red.

Can't find it? If the AI says it can't make files, search "create files" on ChatGPT help ↗ or Claude help ↗, or try one of the other tools.

04

Try to break it Before you trust it.

The AI can say it added a check when it did not. Test each one yourself.

  1. Type tomorrow in a Due date cell. It should say no.
  2. Type 31/02/2026. It should say no.
  3. Delete an Owner. The cell should be highlighted.
  4. Set a due date last week, Status In progress. The row should turn red. Change it to Done. The red should go.
  5. Add a project at the bottom. The dropdowns should work there too.
  6. Count the In progress rows yourself. The Summary should match.

Write down every test that fails. Undo each test with Ctrl + Z or Cmd + Z.

05

Fix it and go live Only what broke.

Go back to the same chat. It still knows how it built the file.

I tested the tracker. These tests failed:
[each failed test: what you did and what happened]

Fix only these problems. Change nothing else.
Tell me what you changed for each one, then give me the new .xlsx file.
  1. Download the new file. Run the failed tests again.
  2. When every test passes, delete the 3 practice rows.
  3. Add your real projects, one row each. Save it in your Clients folder.

The honest part: the tracker won't update itself or chase a client. Check it for 10 minutes each week and send every invoice the Summary counts.
