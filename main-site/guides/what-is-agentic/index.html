What AI agents actually do

Does your task need an agent, or would a simpler tool do? Find the right starting point before connecting anything.

Start with your task

An AI agent is a system configured to carry out a task on your behalf. Instead of stopping after one reply, it can use an AI model to manage several steps and select from the tools and actions it has been given.

A work example

Compare tools without buying one

  1. 01Your job

    Ask for a shortlist from three public pricing pages.

  2. 02The agent's work

    If given web access, it can open the pages, compare plans and flag missing details.

  3. 03Your decision

    Check the sources and choose. It does not sign up or spend for you.

Before you connect it

What can the agent touch?

Tools

A tool is a connection to something else, such as a browser, file, inbox, calendar, customer database or another app. Without a connection, the agent cannot use that system.

Permissions

Permissions control whether the agent can read, draft, update, send, delete or spend. An agent that can read your inbox but cannot send may prepare replies without contacting anyone.

Check both. A convincing answer does not tell you what the agent can read, change or send.

Choose a starting level

How much should it do?

01Let it prepare

The agent researches, sorts or drafts, but cannot change anything. This is the safest place to start.

02Let it propose

The agent prepares an action and waits for your approval. It might draft an email, find a meeting time or prepare a customer update.

03Let it act

The agent completes an action without asking every time. Use this only after you have tested it and confirmed how to stop or reverse the action.

For a first test, let it prepare a result you can inspect before it changes anything.

Try it with one task

Does your task need an agent?

Think of a task you do repeatedly. Open ChatGPT or another work-approved AI chat, copy the prompt, replace the brackets and send it. Do not include private information.

View the complete prompt
Help me decide whether this task needs an AI chat, a normal automation or an AI agent.

The task:
[Describe one task you regularly do.]

The steps I currently follow:
[List the steps you know.]

The information or systems involved:
[List the files, inboxes, apps or data involved.]

What could go wrong:
[Describe the consequence of a mistake.]

Before recommending anything, ask me up to 5 short questions about information you genuinely need.

Then give me:

1. The simplest suitable option: AI chat, automation or AI agent.
2. Why that option fits the task.
3. The minimum information and access it would need.
4. The actions it must never take without approval.
5. A low-risk first test.
6. A clear stopping point if something goes wrong.

Use everyday language. Do not recommend a tool or design the complete system yet.

Check that the answer gives you the simplest option, minimum access, a real approval point, a stopping condition and a reversible first test. If any of those are missing, you are not ready to connect an agent.
