Why does ChatGPT forget what you told it?

It may use past chats, but it does not keep every detail as a rule. Give ongoing work a short Project brief, then check the next answer against it.

Find the right fix

Will you need these facts again?

Use a Project. Save the facts once as instructions, then check the answer in a new chat inside it.

Try it yourself

Make one brief that carries over

The service launch below is an example. Follow it once, then replace the facts with details you are allowed to share.

Step 1 / 3

Create a Project

Open ChatGPT. Select New project in the sidebar and name it Service launch.

Open ChatGPT ↗
Step 2 / 3

Save the brief

Open the Project's ••• menu, choose Project settings, and paste the complete instruction below.

The workDraft a page for a new service.
The audienceSmall business owners choosing between an audit and hands-on help.
The unknownsNo price or launch date has been approved.
The boundaryA person approves the final public wording.

Paste this into Project settings → Instructions. Keep it visible so you can compare the next answer with it.

We are preparing a page for a new service. Use these facts whenever I ask about this launch:

- The page is for small business owners choosing between an audit and hands-on help.
- The page is a draft. A person will approve the final public wording.
- No price has been approved.
- No launch date has been approved.

When you draft or revise anything for this Project:
1. Use only the confirmed facts above and any new facts I give you in the current request.
2. Do not turn a suggestion into an approved offer, price or date.
3. If a request conflicts with these facts, point out the conflict before writing.
4. If you need a missing detail, write “Not decided” and ask one short question. Do not guess.
5. Give me the requested draft first, followed by a short “Needs confirmation” list. If nothing is missing, write “None”.
Step 3 / 3

Test a new chat

Start a new chat inside Service launch. Paste the test request and compare the answer with the four facts below.

Draft a two-sentence introduction for the new service page. Say who it is for and name the two kinds of help. Use the facts saved in this Project. Do not add a price, a launch date or a claim that the wording is approved. After the draft, list anything you still need me to confirm. If you cannot find the brief, tell me before writing.

The test passes if the audience and two service choices stay correct, the draft is not treated as approved, and no price or date is invented.

Keep the brief current. If a price, date or other fact changes, update the Project instructions before the next draft.
