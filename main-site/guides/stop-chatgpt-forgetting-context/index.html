How to Stop Explaining My Business to ChatGPT Every Time

Explain each client once. Every new chat already knows.

Start the guide ↓
Fatiha Chikh Free guide
Shift & Lead

Explain each client only once

You explain the same client to ChatGPT every day. This guide saves those details in a Project (a folder that keeps chats, files and rules together). It takes 30 minutes.

What you end up with

  • One Project for your busiest client or offer
  • A short brief saved inside it
  • Your 2 or 3 main files, with private details taken out
  • Proof it remembers, from 2 new chats

You need a ChatGPT account. Projects may not be on every plan. Copy each prompt as it is and change the [brackets].

01

Pick one client And clean the files.

Start with the client you explain most often. Their files must hold nothing private.

  1. Pick the client or offer you explain to ChatGPT most often.
  2. Find 2 or 3 files: the proposal, call notes, what you deliver.
  3. Save a copy of each. Clean the copy, not the original.
  4. Delete bank details, passwords and personal details.
  5. Swap real names for [client].

Put the clean copies in one folder. You add them in step 04.

02

Make the Project One per client.

Every chat inside the Project uses what you add to it.

  1. Open ChatGPT ↗.
  2. In the left sidebar, click New project.
  3. Name it after the client, like [Client] website rewrite.
  4. Click Create project.
Interview me to write a Project brief for one client or offer.

Ask me these one at a time and wait for each answer:
1. Who is this for? (I may use [client] instead of a name.)
2. What does a good result look like for them?
3. What am I delivering, exactly?
4. What are the deadlines?
5. What tone should everything have?
6. What must you always do, and never say or promise?

Then write the brief with these sections:
Who it's for | Goal | Deliverables | Deadlines | Tone | Rules

Keep it under 1,500 characters.
Use only what I tell you. If something is missing, write [CHECK].
Never make up names, prices, dates or promises.
End with: "If something you need is not in this brief or the files, ask me before you write."

Paste this in the Project's chat box. Answer each question. Read the brief and fix any wrong fact.

Can't find it? OpenAI moves this menu. Search "projects" on OpenAI's help pages ↗.

03

Save the brief Paste it once.

Saved as the Project's instructions, the brief goes into every chat.

  1. Copy the whole brief.
  2. Click the three dots next to the Project name.
  3. Click Project settings or Instructions.
  4. Paste the brief and click Save.

Can't find it? Search "project instructions" on OpenAI's help pages ↗.

04

Add your files Proposal and notes.

Files give ChatGPT the details the brief leaves out.

  1. On the Project page, click Add files.
  2. Pick a clean file from your folder and click Open.
  3. Add the other 1 or 2 files the same way.

Name each file clearly first, like Proposal. A few clear files work best.

05

Test with 2 chats Proof it remembers.

Start a new chat inside the Project. Check its name shows at the top.

Without me explaining anything, tell me in 5 bullets:
who this work is for, the goal, what I'm delivering, the next deadline, and one rule I gave you.
If any of these is missing from the Project, write "Not in the brief".
Never make up names, prices, dates or promises.
  1. Check each answer against your brief.
  2. Any date or price not in the brief was made up. Add a rule against it.
  3. Start a second new chat and ask again. Both must match.

The honest part: ChatGPT can still miss a detail and sound sure. It writes the first draft. You read it before anything goes to a client.
