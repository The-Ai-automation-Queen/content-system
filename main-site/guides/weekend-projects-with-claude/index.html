How to Build Simple Tools for My Business With Claude (No Coding)

You describe the tool. Claude builds it. No code.

Start the guide ↓
Fatiha Chikh Free guide
Shift & Lead

Build the tools you keep wishing for

Small jobs slip when you do them by hand. Here Claude builds a checklist, a calculator and a calendar, with no code from you. It takes 45 minutes.

What you end up with

  • A client checklist for every new yes
  • A price calculator that uses your own prices
  • A post calendar with a month on one screen
  • Four more tools: invoices, enquiries, an FAQ page, a launch countdown

You need a Claude account at claude.ai. The free plan works. Copy each prompt as it is and change the [brackets].

01

Build a tiny test tool See how it works.

Claude builds each tool as an artifact (a small page in the chat you can click). Try a tiny one first.

  1. Open Claude ↗ and click New chat.
  2. Type: Build a simple tick list as an interactive artifact, with 3 tick boxes: Send contract, Send invoice, Book first call.
  3. Press Enter. A panel opens with your tick list.
  4. Click a box. A tick appears.
  5. Click Publish to get a link, or Download to save the file.

Can't find it? Only code, or no panel? Search "artifacts" on Claude's help pages ↗.

02

Build the client checklist Nothing missed after yes.

List every step from a client's yes to their first session. Then nothing gets missed.

Build me a client onboarding checklist as an interactive artifact.

My business: [what you do, in one sentence]
My steps for a new client, in order:
[your steps, one per line]

The tool must:
- Have a box at the top for a code like [client A]
- Show my steps in order, each with a tick box
- Show progress at the top, like "4 of 9 done"
- Have a "Start a new client" button that clears every tick

Use only the steps I give you. If a step is unclear, ask me first.
Easy to read on a phone. Do not connect to any outside website.
  1. Tick two steps. Check it says 2 done.
  2. Check every step is yours, in your order.
  3. Click Start a new client. Every tick should clear.
03

Build the price calculator Your prices, added up.

No more sums by hand on a sales call. You type the prices. Claude never picks them.

Build me a pricing calculator as an interactive artifact.

My packages (pick one):
- [package name]: [price]
- [package name]: [price]

My extras (tick any):
- [extra]: [price]
- [extra]: [price]

The tool must:
- Let me pick one package and tick any extras
- Have a box for a discount, as a percentage
- Show each line of the sum, then the total
- Show the money in [your currency]

Use only the prices I give you. Never change or round them.
If a price is missing, show [CHECK]. Do not connect to any outside website.
  1. Rebuild a quote you already sent.
  2. Check the total matches, to the cent.
  3. Wrong? Use step 05 to fix it.
04

Build the post calendar A month on one screen.

See what goes out, where, and what is still a draft.

Build me a content calendar as an interactive artifact.

Where I post: [for example: LinkedIn, Instagram, my newsletter]
How often: [for example: 3 times a week]
My main topics: [3 to 5 topics]

The tool must:
- Show one month as a grid, with next and last month buttons
- Let me click a day to add a post: platform, topic, one-line idea, status
- Use 3 statuses, each in its own colour: Idea, Draft, Ready
- List this week's posts under the grid

Start it empty. Do not connect to any outside website.
  1. Add one post next week.
  2. Close the tab and open the tool again.
  3. Post gone? Ask for a Download as spreadsheet button in step 05.
05

Fix one thing Test after each change.

Five changes at once can break what works. Ask for one, then test it.

Change one thing in this tool: [the change].
Why: [what happens now, and what should happen].

Keep everything else exactly the same.
Tell me in one line what you changed.

Test the change. Then test one thing that worked before.

The honest part: these tools are for your own use. They can get a sum or a date wrong, so test with numbers you know. Anyone with a published link can open it. Publish only empty tools, never client details.

06

Build four more When you're ready.

Build one at a time, each in a New chat. Test it with something you already know.

Build me an invoice tracker as an interactive artifact.
For each invoice: number, client code like [client A], amount, date sent, date due, paid (tick).
Show unpaid invoices first, overdue ones in red, and the total unpaid at the top.
Start it empty. Do not connect to any outside website.
Build me a lead tracker as an interactive artifact.
For each enquiry: first name or code, where they found me, what they asked, date, next step, status (New, Call booked, Proposal sent, Won, Not now).
Show leads with a next step due today or earlier first.
Start it empty. Do not connect to any outside website.
Build me an FAQ page as an interactive artifact for my clients.
My business: [what you do, in one sentence]
Questions and my answers:
[each question and your answer]

Each question opens to show the answer when clicked. Add a search box.
Use my answers word for word. Do not add your own.
Do not connect to any outside website.
Build me a launch countdown as an interactive artifact.
What I'm launching: [offer or event]
Launch date: [date]
My jobs before launch: [one per line]

Show the days left in large numbers. List my jobs by week, each with a tick box.
Use only the jobs I give you. Do not connect to any outside website.
