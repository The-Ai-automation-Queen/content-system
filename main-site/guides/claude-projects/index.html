Stop repeating your instructions to Claude

Save the format once in a Project. Give Claude fresh notes each time and check what it calls a decision.

Who collects feedback and when?

Build it in Claude

Four short steps

Step 1 / 4

Create a Project

Open Claude’s Projects page. Select + New Project and name it Meeting follow-ups.

Open Claude Projects ↗
Step 2 / 4

Save the instructions

Inside the Project, select Set project instructions. Paste the instruction below and select Save instructions.

View the complete Project instruction
Turn my meeting notes into a short follow-up I can review.
Use these 3 headings: Decisions, Who does what, Questions to resolve.
Under Who does what, show a table with Task, Person and Due date.
Use only the notes in my current message. Write “Not agreed” where a person or date is missing.
Keep suggestions separate from agreed decisions. Don’t carry facts over from other meetings.
Use plain English. Don’t send messages or create tasks in another app.
Step 3 / 4

Try new notes

Start a new chat inside the Project. Paste these invented meeting notes, then send them.

View the complete meeting-note example
Please organise these meeting notes.
We agreed to test a shorter weekly team meeting for 2 weeks. Alex will send the new agenda by Friday. Someone needs to collect feedback, but we didn’t choose who or set a deadline. Recording the meetings was suggested, not agreed.
Step 4 / 4

Check the follow-up

Read Claude’s reply and mark only the points it got right.

0 of 4 points marked. Compare each one with the notes before relying on it.

Try the next meeting without repeating the format. If Claude keeps the headings and separates decisions from suggestions, the saved instruction is doing its job.
