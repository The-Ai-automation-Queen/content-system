Should you use ChatGPT?

Use ChatGPT when you want one flexible place to write, research, work with files or think through a task. You do not need every feature, and you should not connect your work accounts on day one.

Yes, ChatGPT is a useful first AI tool for everyday work. Start with the free plan and one simple task. Keep it only if the result saves you time and is easy to check.

Choose another tool first if your organisation requires an approved system or your work needs to remain inside a specific company platform.

Choose the part you actually need

01

Chat

Use Chat for one question or task. Ask it to explain something, improve a draft, organise notes, compare options or help you think through a problem.

02

Projects

Use a Project when you keep returning to the same work. It keeps related chats, files and instructions together, so you do not need to explain the background every time.

03

Work

Use Work for a longer task that needs several steps, research or a finished deliverable. If it does not appear in your account, ignore it for now because availability varies.

04

Codex

Codex is OpenAI's tool for working with code. If you do not work with software, you do not need it yet.

Match the feature to the job

01

Search

Use Search when the answer may have changed recently. Ask for sources, then open them yourself before using the information.

02

Files and data

Select the + button to attach a document, image or spreadsheet. Say exactly what you want ChatGPT to find, compare or explain, then check the answer against the original file.

03

Images

Upload an image or screenshot and ask a specific question, or ask ChatGPT to create or edit an image. Check text, numbers, logos, faces and small details before using it.

04

Voice

Select the voice button when talking is easier than typing. Review the written result because names, numbers and specialist words can be misunderstood.

05

Canvas

Use Canvas when you want to work through a longer piece of writing or code. Select the section you want to change instead of rebuilding the entire draft.

Check these settings first

Set the account up before you use it for real work.

  1. Choose whether chats help train the models

    On a personal account, open Profile → Settings → Data Controls. Turn off Improve the model for everyone if you do not want new conversations used to improve OpenAI's models.

  2. Check what ChatGPT remembers

    Open Settings → Personalization → Memory. Review what is stored, turn Memory off or use a Temporary Chat when you do not want a conversation added to your history or memory.

  3. Follow your organisation's rules

    Do not place confidential work inside a personal account simply because you pay for Plus or Pro. Use the workspace and tools your organisation has approved.

Connect an app only when it solves a real problem

ChatGPT can connect to email, calendars, cloud storage and other work tools. Do not connect everything because the option exists.

  1. Open the app directory

    Open Settings → Apps, or open the Plugin directory from the tools menu.

  2. Review the access

    Choose the app, read what information and actions it can access, then connect the correct account.

  3. Start with permission prompts

    Choose Always ask when it is available, so ChatGPT asks before it uses the connected app.

  4. Use the app deliberately

    Open a chat and select the connected app from the tools menu only when the task needs it.

  5. Disconnect it properly

    Return to Settings → Apps, select the app and disconnect it. This stops future access but does not remove information already used in previous chats or memories.

Start free and upgrade for a reason

The free plan is enough to find out whether ChatGPT helps with your work.

Consider paying only when you repeatedly reach a limit during useful work, need a feature unavailable on your plan or can clearly see that the time saved is worth the subscription.

Do not upgrade because one vague instruction produced a weak answer. Improve the task, context and checking process first.
