What can Copilot see in your emails, files and meetings?

Run three harmless source checks so you know what Copilot can find before you use it for sensitive work.

Copilot’s answer depends on your work account, licence, permissions and connected sources. Ask it to show the source, then confirm that you can open the same item yourself.

Test one source at a time

01

Email

Use a harmless message you sent to yourself with a unique phrase.

02

File

Use a demo document you own and can open in the same account.

03

Meeting

Use a test event with no guests and a unique title.

04

External source

If Copilot shows a web or connected source, open it and check its origin.

Check access without exposing real work

Create three demo items containing the phrase Cobalt orchard 47.

  1. Ask for the email

    Request the subject and source link for the demo message only.

  2. Ask for the file

    Request the document title and one sentence from the demo file only.

  3. Ask for the meeting

    Request the test event title, date and source only.

  4. Remove the demos

    Delete the test items when you have recorded which sources appeared.

Ask Copilot to show its evidence

Run this separately for the email, file and meeting test.

You are helping me complete one small, practical task. Follow the instructions exactly and do not broaden the job. TASK Find the [EMAIL / FILE / MEETING] in my work account that contains the exact phrase “Cobalt orchard 47”. Return only: 1. the item title or subject; 2. the date; 3. the application where you found it; 4. a direct source link or source reference; 5. one sentence explaining why it matched. Use only sources available through my current work account. If you cannot find exactly one matching item, say what you searched and stop. Do not infer content, contact anyone, edit a file or create an item. WORKING RULES 1. Treat every requirement, limit and stop condition above as mandatory. 2. Use only the information or sources named in the task. Do not invent a fact, name, date, number, quote, result or commitment. 3. If a bracketed detail has not been replaced, or required information is missing, stop and list what I need to provide. Do not guess. 4. Keep the requested structure and size. Do not add a general introduction, repeated summary, extra deliverable or offer to do more. 5. Do not take an external action, change another file or account, contact anyone, publish, purchase, book, delete or send anything unless the task explicitly requests that exact action. BEFORE YOU FINISH 1. Compare the result with every numbered requirement in the task. 2. Check that every fact comes from the material or source I provided. 3. Check that no prohibited action or extra work was added. FINAL RESPONSE - Put the requested result first. - Then add a short section called “Completion check”. - In that section, list each requirement as Passed, Needs checking or Not completed, with one short reason. - If anything is missing or uncertain, label it “Needs checking” rather than filling the gap. Stop when the requested result and completion check are complete.
