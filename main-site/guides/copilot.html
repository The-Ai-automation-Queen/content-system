Should you use Copilot?

Use Copilot when your work already lives in Microsoft tools. The name covers several products, so choose the version that matches your account before you connect anything.

Yes, if you already spend your day in Word, Excel, Outlook, Teams or OneDrive. Copilot is most useful when it can help where the work already happens.

Start with Copilot Chat. Use Microsoft 365 Copilot only when your account includes it and your organisation has approved access to work data.

Choose the Copilot you mean

01

Microsoft Copilot

The general assistant at copilot.microsoft.com and in the Copilot app. Use it for questions, drafts, web research and simple file work.

02

Copilot in Microsoft 365

The assistant inside Word, Excel, Outlook, PowerPoint and Teams. Availability depends on your subscription and account.

03

Microsoft 365 Copilot Chat

The work chat for people signed in with a work or school account. Enterprise data protection applies, but prompts and responses are still logged.

04

Copilot Studio

The advanced route for building and managing agents. Ignore it unless you have a defined process, approved data and an owner for the result.

Use it where it saves a real step

01

Word and PowerPoint

Draft, rewrite or build from a file you already understand. Check facts, meaning and tone before sharing.

02

Excel

Ask it to explain data, suggest formulas or find a pattern. Check formulas and totals yourself.

03

Outlook and Teams

Summarise a thread or meeting and draft a reply. Check names, decisions, dates and actions.

04

Copilot Chat

Research a current question or work through an idea. Open every source that affects a decision.

Start with the right account

Your account changes what Copilot can see and how the data is handled.

  1. Open Copilot

    Go to copilot.microsoft.com and sign in with the account you intend to use.

    Open Copilot ↗

  2. Check the account badge

    Use a work or school account for approved company work. Do not paste work data into a personal account because it feels easier.

  3. Check your plan

    Open the Microsoft 365 app you use and look for Copilot. If it is missing, your plan, administrator or region may not include it.

  4. Start with one simple task

    Use non-confidential information and check the result before adding files, email or meetings.

Connect only what you need

Personal Copilot can connect to Microsoft and Google services. Work connectors are normally controlled by your organisation.

  1. Open Connectors

    On Copilot.com select Profile → Connectors, or select + → Use connectors inside a conversation.

  2. Read the permission

    Select Connect, continue to the service and review which files, email, contacts or calendar information Copilot may access.

  3. Use the connector for one conversation

    Turn on only the connector needed for the task and ask Copilot to include links to the source.

  4. Turn it off

    Return to Profile → Connectors and disable the service. Delete the Copilot conversation separately if it contains connected information.

  5. Ask before using work connectors

    Microsoft 365 connectors are enabled by administrators and respect existing access. Ask your administrator when a connected source should not be available to Copilot.

The advanced route

Copilot Studio is for building agents that use company information or take actions. That creates an access and responsibility problem, not only a prompt-writing task.

Stop before this route unless you can name the job, data sources, permitted actions, failure test and person who approves the result.

Do not build an agent simply because Copilot Studio makes the button available.

  2. Copy and paste

    Select Copy, paste the instruction and replace the bracketed text.

  3. Remove private information

    Remove personal details, confidential work, passwords and customer information.

    Compare every action, person, date and number with your notes before sending anything.

The result is ready only when every action can be traced back to your original notes.

You now know which Copilot to open

Use general Copilot for everyday help, Microsoft 365 Copilot for approved work inside Microsoft apps and Copilot Studio only for a defined agent project.

Keep Copilot if working inside Microsoft saves more time than copying information into another tool.
