Can ChatGPT do the boring checking for you?

Set one public page to check each weekday. Get an update only when the change matters.

Start with a public page

What would be worth an alert?

This example watches a public service-status page. Change the fields to make the instruction yours.

Your instruction
View the complete instruction
Every weekday morning, check https://status.openai.com/.

Only notify me if this condition is met: the ChatGPT service status changes. Compare the page with the previous check before sending an alert.

In the notification, include:
- what changed;
- the current wording or status;
- the source link;
- the time you checked.

If nothing changed, do not notify me. Stop checking 14 days after the task is created.
Make it work

Set the task, then check it

Step 1 / 4

Open Scheduled tasks

Open ChatGPT on the web and go to Scheduled. Availability can vary by account or workspace.

Open Scheduled in ChatGPT ↗
Step 2 / 4

Add the instruction

Use the complete example below and replace only the public URL, condition and stop rule.

Use Copy above, paste the instruction into ChatGPT, and replace the example fields first if you need a different public page.

Step 3 / 4

Check the controls

Review the schedule, time zone, condition and stop rule before confirming.

Check the time zone and notification choice in Settings → Notifications. Keep the stop rule in the instruction if there is no separate end control.

Step 4 / 4

Check it was saved

Find the task in Scheduled and confirm its instruction and next run. Compare any later alert with the public source.

You can check the setup now. If an alert arrives later, compare it with the linked public page before trusting it.

Keep it only if the alerts help. If it sends noise or cannot show what changed, pause it in Scheduled.
