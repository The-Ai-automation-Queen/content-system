Should you let AI connect to your email, files and calendar?

A connection can save time, but it also gives the AI access to information you did not paste into the chat. Connect only what you need and know how to remove it.

Connect an AI tool only when a repeated task genuinely needs information from another service. Start with the smallest amount of access that can complete the job.

A connection may let the tool retrieve email, files, contacts or events. Some connections can also create, edit or delete information after you approve an action.

Start with the smallest level of access

01

Upload one file

Best when the AI needs one document for one task.

02

Connect one service

Useful when you repeatedly need to search that email, drive or calendar.

03

Allow actions

Use only when you understand what the tool can create, edit, send or delete.

  • Show instructions

  • Show instructions

  • Show instructions

    On mobile, open Profile → Connectors. On Copilot.com, use + → Use connectors.

Disconnecting is not the same as deleting

Disconnecting normally stops future access. It does not always remove information already present in a chat or activity history.

ChatGPT says existing conversations remain. Gemini stores connected information separately in Gemini Apps Activity. Copilot responses remain until you delete the conversation. Claude stores retrieved information with the associated chat, which you can delete.

After disconnecting, review the conversation or activity history separately.

Ask 4 questions before connecting

What can it read?

Check whether the permission covers one folder, one account or everything you can access.

Can it change anything?

Look for permission to create, edit, send, share or delete.

Where does the result remain?

Check whether retrieved information appears in chat history, memory or another activity record.

Is there a smaller option?

Ask whether uploading one file can complete the same task.

3. Whether I could complete the task with less access.
