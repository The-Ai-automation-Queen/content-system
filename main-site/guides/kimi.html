Should you use Kimi?

Use Kimi when you want to test long files, agent work or coding from Moonshot AI. Start with the web app and ignore Kimi Code until you are comfortable working with project files and a terminal.

Yes, if long source material, agent tasks or coding are the reason you are looking for another tool. Do not add Kimi simply because a new model scored well on a test.

Start at Kimi.com with public or invented information. Use Kimi Code or the API only when a technical task justifies the setup.

Choose the part you need

01

Kimi Chat

Use the web or app for questions, writing, research and file-based work.

02

Kimi Agent

Use Agent mode for a longer task that needs tools, planning and several steps. Review the plan and result.

03

Kimi Code

Use the coding agent in a terminal or supported editor. It can read and edit files and run commands.

04

Kimi API and open models

Developers can build with Kimi models or run released weights through their own infrastructure.

Start with the web app

Use Kimi like a new provider, not an automatic place for live work data.

  1. Open Kimi

    Go to kimi.com, sign in if required and start a new conversation.

    Open Kimi ↗

  2. Use public or invented material

    Do not upload confidential files until your organisation has reviewed the current privacy terms, processing location and plan.

  3. Choose Chat or Agent

    Use Chat for one answer. Use Agent mode only when the task genuinely needs several steps or tools.

  4. Review the work

    Open sources and files, check every claim and confirm that no action occurred outside the task you asked for.

Give Kimi a job, not a vague test

01

Long documents

Ask for differences, evidence and missing information across sources you already understand.

02

Research

Give a narrow question and require original links, dates and a clear list of unverified claims.

03

Agent work

Ask for a plan before execution and keep logins, purchases, publishing and deletion behind your approval.

04

Coding

Use a copy of a project, review the diff and run tests before accepting changes.

Kimi Code is the advanced route

Stop here unless you work with code or have technical help.

  1. Read the official setup

    Use the current Moonshot AI Kimi Code documentation. The project is evolving, so do not rely on an old installation video.

    Open Kimi Code ↗

  2. Open the correct project

    Start in a copied or version-controlled project folder and sign in using the supported account or API route.

  3. Keep approvals on

    Do not use automatic or approval-skipping modes until you understand every command and file the agent can change.

  4. Review and test

    Inspect the file changes, run the project's tests and keep deployment credentials out of the first task.
