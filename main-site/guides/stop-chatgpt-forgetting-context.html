How to Stop Explaining My Business to ChatGPT Every Time

Save your details once in a ChatGPT Project.

Start the guide ↓
Fatiha Chikh | The AI Automation Queen Free guide
Shift & Lead

ChatGPT forgets what I told it.

A new chat starts from zero. If you keep repeating the same brief, put it in a ChatGPT Project once, and every chat inside that Project can use it.

What you leave with

a working Project, the brief to paste into it, and a 2-chat test that proves it remembers.

How to use this guide: Use the example event first, so you can see whether the second chat keeps the brief without being reminded. Then build a Project for your real work.

01

One question, or ongoing work? Pick the right place.

  • One question: a normal chat is fine.
  • Several chats on the same work (a client, an event, a project): use a Project. It keeps related chats, files and instructions together.
02

The example an event brief that stays the same.

You're planning a 60-minute online session for first-time managers. You need an event description today and an invitation next week. Both must use the same facts.

  1. Open ChatGPT ↗, click New project in the sidebar and call it Autumn event plan.
  2. Open the Project's menu, choose Project settings and paste the brief into the instructions field.

03

The honest part Check before you use it.

A Project keeps instructions, but it doesn't guarantee every answer follows them. That's why the guide ends with a test: if the second chat misses a fact, check that both chats are inside the same Project and that the instructions were saved.

✓

Your prompts Ready to copy.

Project facts
- The event is a 60-minute online session for first-time managers.
- The goal is to help them run a clearer weekly team meeting.
- The tone is practical and calm.
- Do not promise a recording.

For every draft, separate confirmed facts from suggestions. If information is missing, write "Not decided".
Write an event description in 80 words or fewer. Say who it's for, the format and what people will learn. Use only the Project facts. If a detail is missing, write "Not decided".
Write a short invitation for the same event. Include who it's for, the format and what people will learn. Don't promise a recording or set a date.

Pass if: the second chat keeps the audience, format and goal, and doesn't invent a date or a recording.
