Give both tools the same document and instruction. Check the facts, missing details and time spent fixing each result.

01 · What a good answer catches

A small brief with one easy trap

Use this sample to see what you will check later. The budget is proposed, not approved, and the Support owner is missing.

Pilot starts 12 October. Operations will set up the trial. No customer data may be added until the security review is complete. The proposed budget is $2,000; Finance has not approved it. The go/no-go decision is due 26 October. The owner for the Support handover has not been named.
Confirmed

Operations sets up the trial. No customer data goes in before the security review.

Not approved

The $2,000 budget is only proposed.

Missing

No owner is named for the Support handover.

02 · Keep the test fair

Use the same input twice

  1. Use identical inputs. Add the same safe document to each tool and paste the same complete instruction.
  2. Record the model shown. Note the product, model name and date visible in each tool.
  3. Check against the document. Mark every unsupported claim, missed requirement and formatting repair.
  4. Repeat once. Use a second document before changing your regular workflow.

Use the DeepSeek version you can actually access. DeepSeek lists V4.1 Flash as an API release; the model in its chat product may differ. See DeepSeek’s updates ↗

03 · Run the test

Get the complete comparison instruction

Start with the sample above or another document you are allowed to share. Add the same text or file to both tools, then use the exact same instruction.

Get the full document-test instruction and a link back to this example.

Complete instruction
Use only the document I provide. It may be attached or pasted below this instruction.

Create a decision brief with these headings:
1. Purpose
2. 5 key facts
3. Dates and deadlines
4. People or organisations named
5. Decisions already made
6. Questions the document does not answer

For every fact, include the page number and a short supporting extract. If there are no page numbers, name the section or quote the exact line. If you cannot point to supporting text, write "Not found in the document". Do not use outside knowledge. Do not turn a proposal into an approved decision or an estimate into a confirmed fact.

Keep the brief under 500 words. End with a table listing any statement you could not verify in the document.

04 · Check the work

Which result needed less repair?

Score both tools against document 1. Use a different safe document for the second test.

AccuracyEvery claim matches the source document.
CoverageEvery requested part appears in the result.
RestraintMissing information remains missing instead of being guessed.

0 of 2 documents scored. Score accuracy, coverage and restraint, then add both checking times for each document.
