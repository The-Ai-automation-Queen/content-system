How to Get Gemini to Find Things in My Google Drive

Ask a question. Gemini finds the file and quotes the answer.

Start the guide ↓
Fatiha Chikh Free guide
Shift & Lead

Find any answer in your Drive

You open file after file to find one answer. This guide gets Gemini (Google's AI assistant) to find it and quote it. It takes 25 minutes.

What you end up with

  • Gemini connected to the right Google Drive
  • One answer from a file, with the exact sentence
  • Your 10 main files renamed so they are easy to find
  • A 2-minute test for when Gemini can't find a file

You need the Google account that holds your client files. Copy each prompt as it is and change the [brackets].

01

Switch on Drive Done once.

Gemini only searches the account you are signed in to. Most "can't find it" problems start here.

  1. Open Gemini ↗.
  2. Click your picture top right. Check it is the email with your client files.
  3. Click Settings & help, then Apps (or Extensions).
  4. Turn on Google Workspace.
  5. Ask: "Can you see my Google Drive? Name 3 files."

Can't find it? Google moves this menu. Search "connected apps" on Google's Gemini help pages ↗. On a work account, ask whoever runs it.

02

Point at one file The surest answer.

Pick the file yourself. Then Gemini cannot use the wrong one.

  1. Click the + next to the chat box.
  2. Click Add from Drive, find the file and click Insert.
  3. Paste the prompt below with your question.
Use only the file I attached. Answer this question: [your question, for example: what did we agree about the deposit?]

Reply in this order:
1. The exact sentence from the file, word for word, in quotation marks.
2. The heading it sits under.
3. The answer in one short line.

Use only this file. If it does not answer the question, write "Not in this file".
Never make up names, prices, dates or promises.
  1. Copy 4 or 5 words from the quote.
  2. Open the file and press Ctrl + F (or Cmd + F on a Mac).
  3. Paste the words. Nothing found? Do not use the answer.

The honest part: Gemini can miss a file or misread a scan. The 10-second check keeps you from telling a client the wrong thing.

03

Search for the file When you don't know which.

Gemini can search your Drive. Make it show the file before it answers.

Search my Google Drive for: [the file, for example: the call notes for [client] from October].

Do not answer anything yet. List the matching files with the exact name, the date last changed and a link.
Number the list. If nothing matches, write "No match" and do not guess.
Then wait for me to pick a number.

Open the link to check it is the right file. Then type its number and ask your question.

04

Rename your files Client, type, date.

Gemini searches by file name. "Untitled document (3)" is hard to find.

PartExample
Client[client]
TypeProposal, Contract, Call notes, Invoice or Brief
Date2026-10
Help me rename my client files.

Here are my current file names:
[paste your 10 file names, with clients as [client 1], [client 2]]

My rule is: Client - Type - Date
- Type is one of: Proposal, Contract, Call notes, Invoice, Brief
- Date is YYYY-MM

Give me a table: Current name | New name.
Use only what I give you. If you can't tell the type or date, write [CHECK].

In Drive ↗, right-click each file, click Rename and type the new name.

05

Test when it fails 2 minutes.

Either the connection is broken or one file is the problem. This test tells you which.

  1. Make a new Google Doc called Gemini test note.
  2. Type: The colour of the week is teal.
  3. Wait 1 minute, then start a New chat in Gemini.
Find my Google Doc called "Gemini test note" and tell me the colour of the week.

If you can't find it, tell me which Google account you are searching and whether you can see my Drive.
Do not guess the colour.
  1. It says teal? The connection works. Rename the other file, or ask the sender to share it with this email.
  2. It can't find it? Do step 01 again.
