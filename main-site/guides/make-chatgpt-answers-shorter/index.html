Ask for a meeting brief, not an essay

Start with the fictional project in this prompt. Once you see the result, replace its facts with a task from your own work.

  1. 1Open ChatGPT ↗ and start a new chat.
  2. 2Copy the full prompt below and paste it into the message box.
  3. 3Send it, then check the answer against the limits.
Complete prompt
I need to prepare for a 20-minute project check-in. Use only these facts:

We are updating an internal onboarding checklist. The draft is ready. Team leads have not reviewed it. No publication date has been agreed.

Give me:
1. the 3 questions I should ask;
2. the 2 decisions we need to make in the meeting;
3. one sentence I can use to close the meeting if those decisions are still open.

Do not invent an approval, owner or deadline. Do not present a decision we still need to make as one already agreed. Use no introduction, repeated summary or offer to do more. Stop after the closing sentence. Keep the whole answer to 90 words or fewer.
