Introduction

Claude · 10 min read · Beginner

A Claude Project keeps your instructions and reference files together. Save them once; you only add what changes each time.

A guide by Fatiha Chikh | The AI Automation Queen

What you leave with: a meeting-notes Project you can reuse, the instructions to paste into it, and a test note that shows it's working.

01

How to use this guideIn 30 seconds.

Set up the example Project, run the test note, and check the reply uses your headings without you typing them. Then make a Project for your own repeated work.

02

When a Project helpsSame job, again and again.

  • One-off question: a normal chat is fine.
  • The same kind of task every week (meeting notes, client updates, reports): a Project saves the instructions so you stop retyping them.
03

Set up the exampleMeeting notes into actions.

  1. Open Claude ↗, select + New Project and call it Meeting follow-ups.
  2. Select Set project instructions, paste the instructions, then select Save instructions.
  3. Start a chat inside the Project and paste the test note.
The test note

We'll trial a 4-day content calendar next month. Priya drafts the first week by Thursday. Someone should check the budget, but nobody took it. Hiring a freelancer came up, but nothing was agreed.

→
A good reply

Decided: trial a 4-day content calendar next month.

Who does what: Priya · first week · Thursday. Check the budget · Not agreed · Not agreed.

Still open: who checks the budget? Hire a freelancer?

04

The honest partCheck before you use it.

A Project keeps instructions, not judgement. Read each reply against your notes, especially who does what and by when.

✦Your turn

Unlock the 2 prompts.

Your prompts ready to copy.

The Project instructions

You turn my meeting notes into a follow-up I can check in 2 minutes.

Always use 3 headings:
1. Decided
2. Who does what (a table: Task · Person · By when)
3. Still open

Use only the notes in my message. Write "Not agreed" where a person or date is missing. A suggestion is not a decision. Never carry facts over from another meeting. Don't send anything or create tasks.

The test note (send it in a chat inside the Project)

Meeting notes: We'll trial a 4-day content calendar next month. Priya drafts the first week by Thursday. Someone should check the budget, but nobody took it. Hiring a freelancer came up, but nothing was agreed.

Keep it if: the reply used your headings and table without you typing them.
