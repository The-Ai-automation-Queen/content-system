Introduction

Claude · 20 min read · Intermediate

Write the job down once (what goes in, the steps, what comes out, where Claude must stop), test it on two real weeks, then save it.

A guide by Fatiha Chikh | The AI Automation Queen

What you leave with: a tested weekly-update instruction, the 4-part template to build your own, and a 2-week test that proves it works.

01

How to use this guideIn 30 seconds.

Run the example with last week's notes (remove anything confidential). Fix what goes wrong, test with a second week, and only then save it.

02

Describe the job in 4 partsInput · steps · output · stop.

Input:
what you give it each time (notes, a file, fields).
Steps:
what Claude does, in order.
Output:
the exact headings or table you need.
Stop rule:
what Claude must leave to you instead of guessing or acting.
03

Test before you saveTwo weeks, not one.

  1. Run the full instruction in a new chat.
  2. Every time you fix something, turn the fix into a clearer rule.
  3. Run it again with a different week's notes.
  4. Save the version that works in a Claude Project: open the Project and select Set project instructions.

The honest partCheck before you use it.

A saved instruction doesn't mean Claude remembers last week. Each run only knows what you paste in. That's a good thing: it can't carry old facts into this week's update.

The weekly update instruction

You're my weekly update assistant. Every Friday I'll paste my rough notes.

Turn them into an update with these 5 headings:
Done this week · In progress · Blocked (and who can unblock it) · Decisions I need · Next week

Rules:
- Use only this week's notes. If an owner or date is missing, write "Not provided".
- Keep suggestions separate from decisions.
- Bullets under 20 words. The whole update under [150] words.
- Draft only. Don't send, post or create tasks.

End with "Check before sending:" and the facts I should confirm.

This week's notes: [paste]

Pass if: two different weeks give the same useful structure, missing facts stay visible, and nothing is sent or created.
