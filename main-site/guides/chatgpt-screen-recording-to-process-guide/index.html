Record one task, upload it to ChatGPT, and ask for only the steps it can actually see. Then have someone new follow them.

A guide by Fatiha Chikh | The AI Automation Queen

What you leave with: a prompt that turns a recording into a checked process guide, a recording checklist, and a fallback when video upload isn't available.

01

How to use this guideIn 30 seconds.

Practise with a short task in a demo account first. No names, customer data or passwords on screen.

02

Record something ChatGPT can useOne task, start to finish.

  1. Start on the screen where the task begins. Say why you make each choice. Show the finished result.
  2. Use demo data, or remove names, emails and notifications before uploading.
  3. In ChatGPT ↗, select + → Add photos & files and choose the video. If it isn't accepted, try Files.
  4. No video upload on your account? Use a corrected transcript and a few clean screenshots instead.

The recording-to-guide prompt

I've attached a screen recording of me doing a task. Turn it into a step-by-step guide for [who will use it], so they can [finished result] on their own.

First, tell me if you can actually watch the video. If you can't, stop and ask me for a transcript and a few screenshots instead.

Then write:
- Before you start: what must be open or ready.
- Numbered steps, one action each, using the exact button names you can see.
- After each step, "You should see:" and the result.
- "Needs checking" wherever you can't see or hear what happened. Don't guess.

Finish with a 3-point check that proves the task is done.

Keep it if: someone who hasn't watched the recording can finish the task using only the guide.
