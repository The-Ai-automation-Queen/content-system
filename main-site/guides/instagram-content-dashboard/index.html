How to See My Instagram Numbers for Free

Your reach, saves, shares and watch time on one page, free.

Start the guide ↓
Fatiha Chikh | The AI Automation Queen Free guide
Shift & Lead

See your real Instagram numbers

Seeing your real numbers usually means paying for a tool. This guide has Claude Code build your own dashboard instead. It takes 45 minutes.

What you end up with

  • A live dashboard of your reach, saves, shares and watch time
  • Your best days and times to post, from your own posts
  • Your top and bottom posts side by side
  • A token that refreshes itself every 58 days

You need an Instagram Creator or Business account (free: Settings, Account, Switch to Professional Account), plus Claude Code, Node.js and Python 3 installed. Copy each prompt as it is and change the [brackets].

01

Create your Meta app About 8 minutes.

A Meta developer app lets Claude Code read your Instagram numbers. You make it once.

  1. Go to developers.facebook.com ↗ and log in with Facebook.
  2. Click My Apps, then Create App.
  3. Filter by All, pick Manage messaging & content on Instagram, then click Next.
  4. No business portfolio? Choose "I don't want to connect a business portfolio yet". Click Next.
  5. Click Next, then Create App.

Now add yourself as a tester. Without this, nothing connects.

  1. In your app, go to App roles, then Roles.
  2. Click Add People, choose Instagram Tester, add your username and send it.
  3. In Instagram, go to Settings, Website permissions, Tester invites, and accept.
  1. Open Use cases and click Customize next to Manage messaging & content on Instagram.
  2. Open API setup with Instagram business login.
  3. Under Generate access tokens, click Add account and log in to Instagram.
  4. Click Generate token and copy it. It lasts 60 days.
  5. Copy your Instagram app ID and Instagram app secret from the same page.

Can't find it? Meta renames these menus. Look for API setup with Instagram business login on developers.facebook.com ↗.

02

Check the connection Two browser addresses.

Paste each address into your browser with your token. The first gives your user ID. The second lists your posts.

1. Check your token and get your user ID:
https://graph.instagram.com/v21.0/me?fields=id,username&access_token=YOUR_TOKEN

2. Test pulling your posts:
https://graph.instagram.com/v21.0/me/media?fields=id,caption,media_type,timestamp,like_count,comments_count&access_token=YOUR_TOKEN

Save these four values for step 3:
IG_ACCESS_TOKEN=your_token
IG_USER_ID=your_id_from_address_1
IG_APP_ID=your_instagram_app_id
IG_APP_SECRET=your_instagram_app_secret

See a list of posts? It works. Save the four values in a private note.

Get the dashboard prompts.

Enter your name and email. The rest of the guide opens right away. I'll also email you the link, so you can come back later.

03

Set up the project Claude Code writes it.

Open Claude Code. These two prompts make the folder and a small server (it fetches your numbers from Instagram).

Create a folder called ig-dashboard in my current directory. Inside it, create a .env file with these four variables:

IG_ACCESS_TOKEN=
IG_USER_ID=
IG_APP_ID=
IG_APP_SECRET=

Leave the values blank. I'll fill them in.

Open the .env file yourself and paste your four values. On a Mac, press Command + Shift + . to see hidden files.

Inside the ig-dashboard folder, create a Node.js file called proxy.js that:

- Serves static HTML files from the same directory on port 3001
- Loads IG_ACCESS_TOKEN and IG_USER_ID from the .env file in the same folder
- Has a GET /api/ig/account endpoint that calls https://graph.instagram.com/me with fields: id, username, biography, followers_count, media_count, profile_picture_url
- Has a GET /api/ig/media endpoint that fetches the last 50 posts with fields: id, caption, media_type, timestamp, like_count, comments_count, media_url, thumbnail_url, permalink, then for each post fetches insights from /{id}/insights. For VIDEO posts use metrics: reach,saved,views,shares,total_interactions,ig_reels_avg_watch_time,ig_reels_video_view_total_time. For IMAGE and CAROUSEL_ALBUM posts use metrics: views,reach,saved,shares,total_interactions
- Uses only built-in Node.js modules, no npm installs
- Adds CORS headers to all responses

Do not change the metrics. Photos and reels need different ones.

04

Build the dashboard One long prompt.

This prompt writes the whole page. Paste it as it is, in one go.

Create a file called content-dashboard.html in the ig-dashboard folder. It fetches from http://localhost:3001/api/ig/account and http://localhost:3001/api/ig/media on load. Pure HTML, CSS, JavaScript, no external libraries.

Design:
CSS variables: --bg #FFFFFF, --bg2 #FAF7F2, --bg3 #F2F4FF, --bg4 #E8EDFF, --accent #2C4BE0, --green #18794E, --blue #2C4BE0, --purple #6547A5, --text #24211D, --text2 #57534E, --text3 #78716C, --border rgba(36,33,29,0.16). Load Playfair Display, Source Serif 4, Inter and Space Mono from Google Fonts. Use Playfair Display for headings, Source Serif 4 for reading text, Inter for controls and Space Mono for compact labels. Use #FF5733 for heading accents.

Layout:
Sticky left sidebar (200px) + scrollable main content. Sidebar has a logo mark, section labels, nav links with active state (cobalt left border + cobalt text) driven by IntersectionObserver scroll-spy. Refresh Data button and last-updated timestamp at the bottom of the sidebar.

Engagement rate formula: (likes + comments + saves + shares) / reach x 100. Use reach for every post, and views as the fallback when reach is missing. Color tiers: ≥5% green, ≥2% cobalt, below grey.

Section 1: Profile bar (id="overview"):
Avatar image (or 📸 placeholder), @username in large bold, biography, then 3 stat blocks: Followers, Posts, Reach Rate (avgReach / followers x 100 shown as %).

Section 2: Summary Stats:
6 stat cards in one row: Avg Likes (color #FF5733), Avg Comments (blue), Avg Reach (purple), Avg Saves (green), Avg Engagement Rate (cobalt, 2 decimal places), Total Reel Views. Each shows "per post" or relevant subtext.

Section 3: Reel Watch Time (id="watchtime", only if VIDEO posts have ig_reels_avg_watch_time data):
4 cards with colored top borders: Avg Watch Time in seconds (purple), ig_reels_avg_watch_time is in ms so divide by 1000, Total Watch Time in minutes (cobalt), sum ig_reels_video_view_total_time / 60000, Total Views (green), Best Watch Time (blue) showing the reel with highest avg watch time and first 28 chars of its caption.

Section 4: Algorithm Signals (id="signals"):
2 large cards side by side. Saves Rate: total saves / total reach x 100 in green, show "X total saves · Y% of likes become saves", note "Saves = strongest signal to the algorithm. Anything above 2% is solid." Shares Rate: total shares / total reach x 100 in blue, show total shares count, note "Shares push content beyond your audience. 1%+ on reach is strong."

Section 5: Top & Bottom Performers (id="best"):
Two columns. Left: Top 3 (cobalt header). Right: Bottom 3 (grey header). Each row: rank number, thumbnail (or emoji placeholder), caption truncated to one line, time ago + post type below, like count and engagement rate on the right.

Section 6: Engagement Over Time (id="timeline"):
Bar chart of the last 20 posts in chronological order. Each bar = likes + comments. Bar gradient from cobalt (#2C4BE0) at top to transparent at bottom. Show value above bar, date (M/D) below. Height proportional to max value, minimum 3px.

Section 7: Best Time to Post (id="timing"):
Two side-by-side horizontal bar charts. Left: By Day of week, cobalt bars, best day highlighted green with bold label. Right: By Time bucket (6 to 9am, 9 to 12pm, 12 to 3pm, 3 to 6pm, 6 to 9pm, 9pm+, Late 0 to 5am), blue bars, best time highlighted green. Each row shows avg engagement % and post count. Only show time buckets that have at least 1 post.

Section 8: Hashtag Performance (id="hashtags", only if any hashtag used 2+ times):
Card with header row (Tag / Uses / Avg Eng / Avg Likes). Each hashtag row: tag name in blue, proportional bar, use count, avg engagement %, avg likes. Sorted by avg engagement descending. Max 12 tags.

Section 9: All Posts Grid (id="allposts"):
Sort pills: Likes, Comments, Reach, Eng, Saves, Views, Recent. Grid of cards, auto-fill columns min 220px. Each card: thumbnail image (or emoji placeholder), post type badge (Reel=purple, Photo=blue, Carousel=orange), caption with 2-line clamp, 4 metric chips (Likes in #FF5733, Comments in blue, Reach in purple, 4th chip = Views in cobalt for VIDEO or Saves in green for IMAGE/CAROUSEL). For reels with watch time: show avg watch time and saves below metrics. Footer: engagement rate pill (colored by tier), time ago, link to open post on Instagram. Top 3 cards (after current sort) get a cobalt border. Clicking the card opens the post permalink in a new tab.

Want changes? Ask in plain words, like "Change the accent colour to blue."

05

Refresh the token Do not skip this.

Your token stops working after 60 days. This script renews it every 58 days.

Inside the ig-dashboard folder, create a Python script called refresh_token.py that:

- Reads IG_ACCESS_TOKEN from the .env file in the same directory
- Calls https://graph.instagram.com/refresh_access_token?grant_type=ig_refresh_token&access_token=CURRENT_TOKEN
- Gets the new token from the JSON response
- Overwrites the IG_ACCESS_TOKEN value in the .env file with the new token
- Logs each refresh with a timestamp to token_refresh.log in the same folder
- If the refresh fails: logs a FAILED entry AND sends a macOS desktop notification using osascript
- Uses only Python standard library, no pip installs
Set up a cron job that runs refresh_token.py every 58 days at 9am. Use the absolute path to Python (from `which python3`) and the absolute path to the script. Verify the cron entry was created and show it to me.

Test it the next day. Meta only renews a token at least 24 hours old.

On a Mac, if the schedule cannot run, go to System Settings, Privacy & Security, Full Disk Access, and add /usr/sbin/cron.

06

Run it Your numbers, live.

Start the server, then open the page in your browser.

Find your Python path (before prompt 5):
which python3

Test the refresh (at least 24 hours after you generated the token):
python3 /absolute/path/to/ig-dashboard/refresh_token.py

Start your dashboard:
cd ig-dashboard
node proxy.js

Then open this in your browser:
http://localhost:3001/content-dashboard.html

Click any post to open it on Instagram. Use the sort buttons to rank your posts.

The honest part: your token and app secret open your account. Keep them in the .env file only. Never paste them into a chat, and never share the folder.
