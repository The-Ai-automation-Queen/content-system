Plain-English decoder

This sentence uses 5 terms worth unpacking.

Token

A small unit of text used to measure what a model reads and writes.

Ask: Are we paying to send the same unnecessary context every time?

Context window

The finite amount of instructions, conversation and source material the model can consider in one request.

Ask: What must be in context for this task, and what can be left out?

RAG

The system searches approved material first, then gives the relevant passages to the model before it answers.

Ask: Which sources can it retrieve, how current are they, and does the answer cite them?

Agent

A system that can choose and perform several steps toward a goal, often by using tools.

Ask: Which actions can it take, where does it stop, and who approves consequential steps?

MCP

A shared standard for exposing tools and data sources to AI applications.

Ask: What access does this connection grant, and is it read-only or able to make changes?

Take the meeting card

Five questions that work when jargon starts replacing a clear explanation.

Download as Markdown
  1. In plain English, what job does this system complete?
  2. What information does it need, and where does that information go?
  3. What can it do without approval, and what still needs a person?
  4. How will we know when the answer or action is wrong?
  5. What does the full workflow cost—not just the model call?
