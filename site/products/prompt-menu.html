Chez Claude, Starter #1: The Plain Rewrite.

Sample
Chez Claude · Starters · S1 · The Plain Rewrite
Rewrite the message below so a busy person understands it in one read. Short sentences. No jargon. No hype. Keep every fact, drop every filler word. Message: [paste your message, with names swapped for [Client] / [Me] and any real numbers rounded]

Use when: you wrote something in five minutes and it shows. Run this before you hit send on any email, update, or post.

Every one of the 150 prompts is built the same way: redact names to [Client]/[Me], round the numbers, never paste credentials. The pack models the habit on every single card, so it becomes automatic, not a rule you have to remember.
