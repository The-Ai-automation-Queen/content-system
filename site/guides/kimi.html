Tool verdict / Moonshot AI

Kimi

A serious coding tool at a fraction of the price, with the same hosting question as DeepSeek.

  • Best forLong coding sessions, and turning a prompt into slides or a site.
  • Careful withThe same data question, and paid tiers that climb quickly.
  • What I would doTry it free. Only pay if you're writing code most days.

Where it earns its keep

Kimi comes from Moonshot AI, and its reputation is built on one thing: coding. It will work on a piece of software for hours rather than minutes, and it holds the thread across that time better than most. Kimi Code, its coding tool, is free, which for a small development team is a serious proposition.

The second thing worth knowing is that it will produce a slide deck or a working website from a description, and hand you the actual artifact rather than instructions for building one. Screenshot to code works too: show it a picture of an interface and it will build something that resembles it. For a founder putting together a rough prototype before spending money on a designer, that's genuinely useful.

Its deep thinking mode goes further than most before answering, and Agent Swarm, on the higher tiers, runs many instances in parallel on one problem. That's a real capability and, at this price, an unusual one.

Where it'll burn you

It's the same jurisdiction question as DeepSeek and it deserves the same plain answer. Moonshot is a Chinese company and the hosted service is operated under Chinese law. If you wouldn't put your client's contract on it, don't put your client's contract on it. The open weights are published, so self-hosting is an option if you have a real reason to be here.

The pricing surprises people. It reads as cheap because the entry tier is nineteen dollars, and then the tiers climb to thirty-nine, ninety-nine and one hundred and ninety-nine. The features people actually want, the swarm and the higher limits, live near the top. Read the whole table before you decide it's the cheap option.

And for ordinary business work, writing, summarising, thinking through a decision, it's not better than what you already have. This is a specialist tool that happens to have a chat interface, not a general assistant.

Do this

If you're here for the coding, test it on a real piece of your own work before subscribing. Not a toy problem. Something that has already annoyed you once this month. That's the only test that tells you anything.

Cheap at the door and expensive at the tier you actually need. Read the whole table.

What I'd actually do

Start free and use Kimi Code, since it costs nothing. Give it a week on real work. If you're writing software most days and it's holding up, the nineteen dollar tier is easy to justify.

If you're not writing code, there's nothing here for you that ChatGPT or Claude doesn't already do, and those come without the jurisdiction conversation. That's the honest recommendation.

The words you'll keep hearing

  • Kimi Code. The coding tool. Free, and the main reason to be here.
  • Agent Swarm. Many instances working the same problem in parallel. Impressive, and only on the higher tiers.
  • Deep thinking. A long reasoning pass before it answers. Slow and noticeably better on hard problems.
  • Screenshot to code. Show it a picture of an interface, get something that resembles it back.
  • Open weights. The published model files, so you can run it on your own hardware.

Is it the right one for you?

Yes, if you write software most days, if cost matters, and if you're working on things that aren't confidential, or you're willing to self-host.

No, if you're a non-technical business owner looking for a daily assistant. Nothing here beats what you would get from ChatGPT or Claude, and those don't come with a jurisdiction question attached.
