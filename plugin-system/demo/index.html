Plugin Demo

This page shows 3 real examples of how customers customize the plugin with their own content, branding, and metrics.

EXAMPLE 1

Minimal Setup (just paste and go)

Customer adds two lines — zero configuration needed:

<div id="my-plugin"></div> <script src="plugin.js" data-license="DEMO" data-container="#my-plugin"></script>
EXAMPLE 2

Branded with Custom Content

Customer personalizes every label, adds their branding, and hooks into results:

<script> window.MyPluginConfig = { title: "Blog Post Checker", subtitle: "Make sure your post is ready to publish", placeholder: "Drop your blog post draft here...", buttonText: "Check My Post", emptyText: "Drop your draft above first!", poweredBy: false, onAnalyze: function(results) { console.log("Post stats:", results); } }; </script> <div id="blog-checker"></div> <script src="plugin.js" data-license="KEY" data-container="#blog-checker" data-accent="#e84393"></script>
The customer changed: title, subtitle, placeholder, button text, empty message, accent color, and turned off the "Powered by" footer.
EXAMPLE 3

Custom Metrics + Dark Theme

Customer adds their own calculated fields — no code changes to the plugin needed:

<script> window.MyPluginConfig = { title: "SEO Content Scorer", subtitle: "Optimize your content for search engines", buttonText: "Score It", showAvgLength: false, customMetrics: [ { label: "paragraphs", compute: function(text) { return text.split(/\n\n+/).filter(function(p) { return p.trim(); }).length; } }, { label: "keyword density", compute: function(text) { var words = text.toLowerCase().split(/\s+/); var freq = {}; words.forEach(function(w) { freq[w] = (freq[w]||0) + 1; }); var top = Object.entries(freq).sort(function(a,b) { return b[1] - a[1]; })[0]; return top ? top[0] + " (" + top[1] + "x)" : "—"; } } ] }; </script>

Full Configuration Reference

<script> window.MyPluginConfig = { // ── Content & Labels ────────────────────── title: "Your Tool Name", // heading text subtitle: "A helpful description", // optional subheading placeholder: "Enter text here...", // textarea placeholder buttonText: "Go", // button label emptyText: "Nothing to analyze.", // shown when input is empty // ── Branding ────────────────────────────── logo: "https://yoursite.com/logo.png", poweredBy: false, // hide "Powered by" footer // ── Feature Toggles ────────────────────── showWords: true, showSentences: true, showReadingTime: true, showAvgLength: false, // ── Custom Metrics ──────────────────────── customMetrics: [ { label: "characters", compute: function(text) { return text.length; } } ], // ── Callbacks ───────────────────────────── onAnalyze: function(results, text) { // Do something with the results // e.g. send to analytics, update other UI }, onReady: function(rootElement) { // Plugin is rendered and ready } }; </script> <!-- Then load the plugin --> <div id="my-plugin"></div> <script src="https://cdn.yoursite.com/plugin.min.js" data-license="CUSTOMER-KEY" data-container="#my-plugin" data-theme="light" data-accent="#6c5ce7" ></script>
