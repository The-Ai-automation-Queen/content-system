# Vault Audit

You run the weekly pipeline health check on `content-vault.md` for Fatiha Chikh.
The audit answers one question: **is the content pipeline healthy, and what is the
single most important thing to do about it?** Read `CLAUDE.md` first.

---

## What to check

Parse every entry in `content-vault.md` (numbered `## ENTRY NNN` plus any
unnumbered ready/draft stubs) and report:

1. **Status summary** — counts of `READY TO POST`, `DRAFT`, `POSTED`, total.
   Flag loudly if `POSTED` is zero while a backlog of ready pieces exists.
2. **Stale drafts** — anything older than 7 days (staleness threshold = today − 7).
   List entry, date, platform, title, and days stale.
3. **Platform coverage** — what shipped in the last 2 weeks per platform, last
   entry date per platform, and the ready/draft distribution across platforms.
4. **Ready-to-post backlog** — the full list, oldest first, with days unpublished.
5. **Recommended next actions** — immediate / short-term / structural, prioritized.

---

## Output

`reports/vault-audit-YYYY-MM-DD.md`, matching the existing report structure:

```
# Content Vault Audit — YYYY-MM-DD
**Audit date:** ... **Vault file:** content-vault.md **Entries audited:** N
## 1. Status Summary        (table)
## 2. Stale Drafts          (table, with days-stale range)
## 3. Platform Coverage     (last 2 weeks + full distribution)
## 4. Ready to Post — Full List
## 5. Recommended Next Actions   (Immediate / Short-term / Structural)
---
*Report generated by automated vault audit — YYYY-MM-DD*
```

Use `DD/MM/YYYY` when quoting vault dates; `YYYY-MM-DD` for the report date/filename.

---

## The standing judgment

The recurring finding is a large `READY TO POST` backlog with zero `POSTED`. When
that is true, the #1 recommendation is always **publish the backlog and record
`POSTED` + date** — not produce more drafts. Say this plainly. Producing more on
top of an unposted backlog is motion without progress (see `ROADMAP.md`).

## After saving
Give the operator the counts, the staleness range, and the single highest-leverage
next action in a few lines.

## What this skill does not do
- Does not edit or publish content — it only reports on the pipeline.
- Does not overwrite past audits.
