Beyond #016: the campaign run picks the next 3 most audience-relevant
roles from the departments roster (3 different departments per wave) and
assigns names at pick time. Priority lens: highest felt pain for
non-technical founders first (money chasing, time leaks, follow-up),
infrastructure roles later. At 3/week the full 99 completes in roughly
8 months.

Rules:
- A planned row can be reordered; a hired badge is permanent history.
- PROOF candidates get checked for receipts each run; an employee whose
  real instance starts running gets upgraded from PLAYBOOK to PROOF in
  its episode.
